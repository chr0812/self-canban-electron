# 일정관리 (self-canban)

내 PC 한 대에서 혼자 쓰는 **칸반 보드 일정 관리 프로그램**입니다.
개발 버그나 할 일을 카드로 적어 두고, **할 일 → 진행 중 → 완료**로 옮기면서 진행 상황을 한 화면에서 봅니다. 마감일이 있는 카드는 **캘린더**로도 볼 수 있습니다.

- 회원가입, 로그인, 서버가 **없습니다**. 입력한 내용은 **내 PC 안에만** 저장됩니다.
- **인터넷이 없어도** 모두 동작합니다.
- Windows 11 (64비트) 용입니다.

---

## 1. 이 프로그램으로 할 수 있는 것

| 기능 | 설명 |
|---|---|
| 카드 만들기 | 제목, 종류(개발 버그 / 할 일), 상세 설명, 마감일, 우선순위, 추가 메모를 적습니다 |
| 상태 옮기기 | 카드를 끌어서 다른 칸으로 놓거나, 카드의 메뉴로 옮깁니다 |
| 진행 기록 | 카드마다 "검토해 보니 이랬다", "추가 이슈가 생겼다" 같은 기록을 날짜와 함께 남깁니다 |
| 캘린더 | 마감일이 있는 카드를 달력으로 봅니다. 달력의 카드를 끌어 다른 날짜에 놓으면 마감일이 바뀝니다 |
| 보관함 | 끝난 카드를 보드에서 치워 두는 곳입니다. 나중에 다시 찾아볼 수 있습니다 |
| 검색·걸러보기 | 제목으로 검색하고, 종류나 우선순위로 걸러 봅니다 |
| 마감 지난 표시 | 마감일이 지났는데 아직 끝나지 않은 카드를 눈에 띄게 보여 줍니다 |
| 밝은 화면 / 어두운 화면 | 처음에는 밝은 화면이고, 원하면 어두운 화면으로 바꿉니다 |

## 2. 설치하고 실행하기 (처음 한 번만)

설치 프로그램은 없습니다. **압축 파일을 풀고 `일정관리.exe`를 실행하면 끝**입니다.

### 2-1. 내려받기
1. 이 저장소 첫 화면 오른쪽의 **Releases**(릴리스)를 누릅니다.
2. 가장 위에 있는 항목의 **Assets** 안에서 `self-canban-windows-x64.zip`을 눌러 내려받습니다.
   - 파일 크기가 크니(약 150MB 안팎) 시간이 걸릴 수 있습니다.

### 2-2. 압축 풀기
1. 내려받은 zip 파일에서 마우스 오른쪽 버튼 → **모두 압축 풀기**를 누릅니다.
2. 풀 위치는 어디든 괜찮습니다. 예: `C:\프로그램\일정관리`
3. 압축을 푼 폴더 안에 **`win-unpacked`** 폴더가 있고, 그 안에 `일정관리.exe`가 있습니다.

> ⚠️ **`일정관리.exe` 파일만 따로 옮기면 실행되지 않습니다.** `win-unpacked` 폴더 안의 파일들이 모두 같이 있어야 합니다. 폴더째로 옮기거나 보관하세요.

### 2-3. 실행하기
1. `win-unpacked` 폴더 안의 **`일정관리.exe`** 를 더블클릭합니다.
2. 처음 실행할 때 파란 **"Windows의 PC 보호"** 창이 뜰 수 있습니다. 이 프로그램은 회사 인증서로 서명하지 않아서 생기는 정상적인 경고입니다.
   1. 창에서 **추가 정보**를 누릅니다.
   2. 나타난 **실행** 버튼을 누릅니다.
3. 잠시 뒤 "일정관리" 창이 열립니다. 이제 아무것도 없는 빈 보드가 보입니다.

### 2-4. 바탕화면에 바로 가기 만들기 (선택)
`일정관리.exe`에서 마우스 오른쪽 버튼 → **바로 가기 만들기**를 누르고, 만들어진 바로 가기를 바탕화면으로 옮깁니다.

## 3. 사용 방법 (처음 쓰는 분을 위한 순서)

화면 왼쪽에는 메뉴(사이드바)가 있고, 오른쪽이 본 화면입니다.

```
┌────────────┬────────────────────────────────────────────┐
│ 일정관리   │  [검색]                      [카드 만들기]  │
│ 보드  (N)  ├────────────┬────────────┬──────────────────┤
│ 캘린더     │  할 일     │  진행 중   │  완료            │
│ 보관함 (N) │  ┌──────┐  │  ┌──────┐  │  ┌──────┐        │
│ ─────────  │  │ 카드 │  │  │ 카드 │  │  │ 카드 │        │
│ 종류       │  └──────┘  │  └──────┘  │  └──────┘        │
│ 우선순위   │            │            │                  │
│ 화면 밝기  │            │            │                  │
│ 저장 상태  │            │            │                  │
└────────────┴────────────┴────────────┴──────────────────┘
```

### 3-1. 카드 만들기
1. 오른쪽 위의 **카드 만들기** 버튼을 누릅니다.
2. **제목**을 적습니다. 제목은 꼭 있어야 합니다. 나머지는 비워 둬도 됩니다.
3. 필요하면 아래 항목을 고릅니다.
   - **종류**: `개발 버그` 또는 `할 일` (고르지 않으면 `할 일`)
   - **상태**: `할 일`(기본) 또는 `진행 중`. 이미 시작한 일이면 처음부터 `진행 중`으로 만들 수 있습니다
   - **마감일**: 칸 오른쪽의 달력 모양을 눌러 날짜를 고르거나, 직접 숫자로 적습니다. 지우면 마감일이 없는 카드가 됩니다
   - **우선순위**: `없음`, `낮음`, `중간`, `높음`
   - **상세 설명**, **추가 메모**: 자유롭게 적습니다
4. **저장** 버튼을 누릅니다. 카드가 선택한 상태의 칸에 나타납니다.

> 제목을 비우고 저장하면 오류 문구가 나오고 카드가 만들어지지 않습니다. 없는 날짜(예: 2월 30일)를 마감일로 넣어도 마찬가지입니다.

### 3-2. 카드 상태 옮기기
카드는 진행되는 만큼 칸을 옮깁니다. 방법은 두 가지입니다.
- **끌어서 놓기**: 카드를 마우스로 누른 채 다른 칸 위로 끌어 놓습니다.
- **메뉴로 옮기기**: 카드의 메뉴(점 세 개 모양)를 눌러 **상태 이동**에서 옮길 칸을 고릅니다.

완료한 카드를 다시 진행 중이나 할 일로 되돌릴 수도 있습니다.

### 3-3. 카드 열어서 고치기 · 진행 기록 남기기
1. 카드를 누르면 상세 창이 열립니다.
2. 제목, 마감일 같은 내용을 고치고 **저장**을 누릅니다.
3. 창 아래쪽 **진행 기록**에서 기록을 남깁니다.
   1. **기록 내용** 칸에 적습니다. 예: "원인은 날짜 계산 오류로 보임"
   2. **기록 추가**를 누릅니다.
   3. 기록은 남긴 순서대로 쌓이고, 남긴 때의 카드 상태(할 일 / 진행 중 / 완료)가 함께 표시됩니다.
   - 기록은 카드를 저장한 뒤에 남길 수 있습니다.

### 3-4. 카드 삭제하기
1. 카드를 열어 **삭제**를 누릅니다.
2. 확인 줄이 나오면 **삭제 확인**을 눌러야 지워집니다. 카드와 그 카드의 진행 기록이 함께 사라지고 **되돌릴 수 없습니다**.
3. 취소하면 카드가 그대로 남습니다.

### 3-5. 캘린더로 보기
1. 왼쪽 메뉴의 **캘린더**를 누릅니다.
2. 마감일이 있는 카드가 그 날짜 칸에 보입니다. 마감일이 없는 카드는 캘린더에 나오지 않고 보드에서만 보입니다.
3. 위쪽에서 **월 / 주** 보기를 바꾸고, 화살표로 달이나 주를 이동합니다. **오늘로 이동**을 누르면 오늘로 돌아옵니다.
4. 카드를 누르면 상세 창이 열립니다.
5. **마감일 바꾸기**: 카드를 끌어서 다른 날짜 칸에 놓으면 마감일이 그 날짜로 바뀝니다. 같은 칸에 놓으면 아무 일도 일어나지 않습니다.
6. 하루에 카드가 많으면 "+N건 더 보기"로 나머지를 볼 수 있습니다.

### 3-6. 끝낸 카드 보관하기
1. 완료 칸의 카드에서 **보관**을 누르고 **보관 확인**을 누릅니다.
2. 카드가 보드와 캘린더에서 사라지고 **보관함**으로 갑니다. 완료한 카드만 보관할 수 있습니다.
3. 왼쪽 메뉴의 **보관함**에서 보관한 카드를 찾아보고 내용을 읽을 수 있습니다. 보관한 카드는 고칠 수 없고, 삭제만 할 수 있습니다.

### 3-7. 검색하고 걸러 보기
- 위쪽 **검색** 칸에 글자를 입력하면 제목에 그 글자가 들어 있는 카드만 보입니다.
- 왼쪽 메뉴의 **종류**, **우선순위**에서 항목을 고르면 그 조건에 맞는 카드만 보입니다. 처음에는 두 곳 모두 **전체**가 선택되어 있고(조건 없음), **전체**를 다시 고르면 조건이 풀립니다.
- 조건을 한꺼번에 풀려면 **조건 모두 지우기**를 누릅니다.
- 보관함에서도 같은 방법으로 찾습니다.

### 3-8. 마감이 지난 카드
마감일이 오늘보다 앞이고 아직 완료하지 않은 카드는 삼각형 표시와 "N일 지남" 글자로 눈에 띄게 보입니다. 완료한 카드는 마감이 지났어도 표시되지 않습니다.

### 3-9. 화면 밝기 바꾸기
왼쪽 메뉴 아래쪽 **화면 밝기**에서 **밝은 판** / **어두운 판**을 고릅니다. 고른 화면은 다음에 열 때도 유지됩니다.

## 4. 내 데이터는 어디에 저장되나요?

- 카드를 만들거나 옮길 때마다 **자동으로 저장**됩니다. 따로 저장 버튼을 누르지 않아도 됩니다.
- 왼쪽 메뉴 맨 아래에 **내 PC에 저장됨**이 보이면 저장이 끝난 것입니다. **저장 중**이 보일 때는 잠깐 기다리세요.
- 저장 위치는 다음 폴더입니다.

```
C:\Users\<내 사용자 이름>\AppData\Roaming\self-canban\
```

빠르게 열려면: 키보드의 **윈도우 키 + R** → `%APPDATA%\self-canban` 입력 → 확인.

이 폴더 안의 **`kanban-data.json`** 파일 하나에 모든 카드와 기록이 들어 있습니다.

### 데이터 백업하기 (권장)
이 프로그램에는 백업 기능이 없습니다. PC가 고장 나면 데이터를 되살릴 방법이 없으니, 가끔 직접 복사해 두세요.
1. 프로그램을 **닫습니다**.
2. `%APPDATA%\self-canban` 폴더를 엽니다.
3. `kanban-data.json` 파일을 USB나 클라우드 등 다른 곳에 복사해 둡니다.

### 다른 PC로 옮기기 / 백업에서 되살리기
1. 새 PC에서 프로그램을 한 번 실행했다가 **닫습니다**(폴더가 만들어집니다).
2. 복사해 둔 `kanban-data.json`을 `%APPDATA%\self-canban` 폴더에 **덮어씁니다**.
3. 프로그램을 다시 실행합니다.

## 5. 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| 실행이 안 되고 "Windows의 PC 보호"가 뜬다 | **추가 정보 → 실행**을 누르세요 (2-3 참고) |
| `일정관리.exe`를 더블클릭해도 아무 일이 없다 | `win-unpacked` 폴더 안의 다른 파일이 지워지지 않았는지 확인하세요. 압축을 다시 풀어 폴더 전체를 쓰세요 |
| "저장하지 못했습니다"가 뜬다 | 입력한 내용은 화면에 남아 있습니다. 디스크 공간이나 폴더 권한을 확인하고 **다시 저장**을 누르세요 |
| "저장된 데이터를 읽지 못했습니다"가 뜬다 | 프로그램을 닫고 `%APPDATA%\self-canban` 폴더의 `kanban-data.json`을 다른 이름으로 바꾼 뒤 다시 열면 직전 저장본(`kanban-data.json.bak`)으로 열립니다. 화면의 안내 문구도 같은 방법을 알려 줍니다. 읽지 못한 데이터는 새 저장으로 덮어쓰이지 않습니다 |
| 이전에 어두운 화면으로 바꿨는데 계속 어둡다 | 저장된 선택이 우선합니다. 왼쪽 메뉴에서 **밝은 판**을 고르세요 |
| 같은 프로그램을 두 번 실행했다 | 같은 데이터를 두 창이 쓰면 마지막에 저장한 쪽 내용이 남을 수 있으니 한 번에 하나만 쓰세요 |

### 프로그램 지우기
`일정관리` 폴더(압축을 푼 폴더)를 삭제하면 프로그램이 지워집니다. 내 카드 데이터는 지워지지 않고 `%APPDATA%\self-canban` 폴더에 남아 있으니, 데이터까지 지우려면 그 폴더도 삭제하세요.

## 6. 개인정보와 보안

- 이 프로그램은 **네트워크에 연결하지 않습니다.** 입력한 내용은 PC 밖으로 나가지 않습니다.
- 계정도, 광고도, 통계 수집도 없습니다.
- 글꼴은 프로그램 안에 들어 있어 따로 내려받지 않습니다.

## 7. 개발자를 위한 안내

프로그램만 쓰는 분은 이 아래를 읽지 않아도 됩니다.

### 구성
- Electron 45 + React 19 + TypeScript 6, 빌드는 electron-vite.
- 데이터는 앱 데이터 폴더의 JSON 파일 하나에 원자적으로 저장합니다.
- 소스는 `app/`에 있습니다. `docs/`에는 인터뷰, PRD, 명세, 설계, 시험 보고서가 있고, `scripts/`, `.claude/`, `contracts/`는 이 프로젝트를 만든 기획~구현 절차(하네스)입니다.

### 소스로 실행하기
Node.js **22.13 이상**이 필요합니다. 설치할 때는 인터넷이 필요합니다.

```bash
cd app
npm ci           # package-lock.json 에 적힌 버전 그대로 설치
npm run dev      # 개발용 실행 (데이터는 %APPDATA%\self-canban-dev 에 저장)
```

| 명령 | 설명 |
|---|---|
| `npm run build` | 타입 검사와 빌드 |
| `npm run start` | 빌드 결과를 실행 |
| `npm run lint` | 코드 검사 |
| `npm test` | 단위 시험 (Vitest) |
| `npm run test:e2e` | 화면 시험 (Playwright, 실제 Electron 창을 띄웁니다) |
| `npm run package` | `app/release/win-unpacked/` 에 포장 (아래 참고) |

포장할 때 다른 프로그램(예: 폴더를 감시하는 도구)이 만들어지는 파일을 열고 있으면 이름 바꾸기 오류(EPERM/EBUSY)가 날 수 있습니다. 그럴 때는 출력 위치를 프로젝트 밖으로 바꿉니다.

```bash
npx electron-builder --win --dir --config electron-builder.yml --config.directories.output=C:/출력/폴더
```
