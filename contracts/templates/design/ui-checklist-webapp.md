# 웹앱(SaaS) UI/UX 조사 체크리스트

## 필수 조사 항목

### 레이아웃
- [ ] 패턴 선택: 사이드바형 / 탑바형 / 대시보드형 / 하이브리드
- [ ] 사이드바 접기/펼치기 (collapsible)
- [ ] 콘텐츠 영역 최대 너비
- [ ] 멀티패널 (마스터-디테일, 스플릿 뷰)

### 네비게이션
- [ ] GNB 구조 (1뎁스, 2뎁스)
- [ ] 브레드크럼
- [ ] 커맨드 팔레트 (Cmd+K)
- [ ] 탭/서브탭 패턴
- [ ] 사이드바 그룹핑/카테고리

### 데이터 표시
- [ ] 테이블 패턴: 정렬, 필터, 페이지네이션, 가상 스크롤
- [ ] 차트/그래프 유형 (대시보드용)
- [ ] 카드 vs 리스트 vs 테이블 전환
- [ ] 데이터 밀도 조절 (compact/comfortable/spacious)
- [ ] 실시간 업데이트 표시 (뱃지, 토스트, 인라인)

### 입력/폼
- [ ] 인라인 편집 vs 모달 편집 vs 전체 페이지 편집
- [ ] 폼 유효성 검사 시점 (onBlur/onChange/onSubmit)
- [ ] 자동 저장 vs 명시적 저장
- [ ] 멀티스텝 폼 (위자드)
- [ ] 벌크 액션 (다중 선택 → 일괄 처리)

### 키보드/접근성
- [ ] 키보드 단축키 매핑
- [ ] Tab 순서 (포커스 관리)
- [ ] 스크린리더 지원 수준
- [ ] WCAG 2.1 AA 대비 비율

### 상태 관리 UX
- [ ] 글로벌 로딩 vs 섹션별 로딩
- [ ] 낙관적 업데이트 (Optimistic UI)
- [ ] 에러 바운더리 범위
- [ ] 세션 만료 처리
- [ ] 동시 편집 충돌 UX

### 반응형
- [ ] 브레이크포인트 전략
- [ ] 사이드바 → 드로어 전환 기준
- [ ] 테이블 → 카드 전환 기준
- [ ] 터치 디바이스 대응 (태블릿)

### 고급 패턴
- [ ] 다크모드
- [ ] 다국어 (RTL 포함)
- [ ] 역할별 UI 분기 (admin/user)
- [ ] 온보딩 투어 / 코치마크
- [ ] 알림 센터

## 벤치마킹 관점

동종 SaaS 분석 시 확인할 항목:
| 관점 | 확인 내용 |
|------|----------|
| 대시보드 | 첫 화면 정보 밀도, 위젯 구성, 커스터마이징 |
| 핵심 워크플로우 | CRUD 완료까지 클릭 수, 인라인 편집 여부 |
| 네비게이션 | 뎁스, 검색, 커맨드 팔레트 |
| 데이터 처리 | 테이블 기능, 필터, 내보내기 |
| 설정/관리 | 설정 페이지 구조, 권한 관리 UI |
