# 모바일앱 UI/UX 조사 체크리스트

## 필수 조사 항목

### 네비게이션
- [ ] 패턴 선택: 하단 탭바 / 드로어 / 스택 네비게이션
- [ ] 탭 개수 (권장 3~5개)
- [ ] 뒤로가기 동작 (Android 물리 버튼 / iOS 스와이프)
- [ ] 딥링크 구조

### 터치 인터랙션
- [ ] 터치 타겟 최소 사이즈 (iOS: 44pt, Android: 48dp)
- [ ] 제스처 매핑: 스와이프, 풀투리프레시, 롱프레스, 핀치
- [ ] 터치 피드백 (리플, 햅틱)
- [ ] 엣지 스와이프 충돌 방지

### 화면 구성
- [ ] Safe Area 대응 (노치, 다이나믹 아일랜드, 하단 바)
- [ ] 상태바 스타일 (라이트/다크)
- [ ] 하단 시트 패턴 (모달 대체)
- [ ] 풀스크린 vs 카드형 화면 전환

### 입력 UX
- [ ] 키보드 회피 (입력 필드 가림 방지)
- [ ] 입력 타입별 키보드 (숫자, 이메일, URL)
- [ ] 자동완성 / 자동수정
- [ ] 바이오 인증 (Face ID, 지문)

### 상태 처리
- [ ] 오프라인 모드 UX
- [ ] 로딩: 스켈레톤 / 시머 / 스피너
- [ ] 빈 상태 (Empty State + CTA)
- [ ] 에러 복구 (재시도, 풀다운 리프레시)
- [ ] 백그라운드 → 포그라운드 복원

### 플랫폼 가이드라인
- [ ] iOS: Human Interface Guidelines (HIG)
- [ ] Android: Material Design 3
- [ ] 크로스플랫폼 시 통합 전략

### 퍼포먼스 UX
- [ ] 첫 화면 로딩 시간 (목표치)
- [ ] 이미지 로딩 전략 (프로그레시브, 블러 해시)
- [ ] 리스트 가상화 (대량 데이터)
- [ ] 애니메이션 60fps 유지

### 알림/온보딩
- [ ] 푸시 알림 권한 요청 시점
- [ ] 온보딩 플로우 (스킵 가능 여부)
- [ ] 앱 업데이트 강제/권장 UX

## 벤치마킹 관점

동종 앱 분석 시 확인할 항목:
| 관점 | 확인 내용 |
|------|----------|
| 첫 화면 | 진입 후 첫 화면 구성, 핵심 액션까지 탭 수 |
| 네비게이션 | 탭 구조, 뎁스, 이동 패턴 |
| 핵심 플로우 | 메인 기능 완료까지 단계 수 |
| 마이크로 인터랙션 | 애니메이션, 전환, 피드백 |
| 에러/엣지 | 오프라인, 에러, 빈 상태 처리 |
