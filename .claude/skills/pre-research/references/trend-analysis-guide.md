# Trend Analysis Guide

시장 트렌드 및 기술 트렌드 분석 절차와 출력 형식을 정의한다.

## 수행 절차

### 1. 시장 트렌드

- 최근 1~2년 주요 변화
- 사용자 니즈/행동 변화
- 투자/성장 방향 (VC 투자, M&A)
- 규제 환경 변화
- 시장 규모 및 성장률 (가능하면)

### 2. 기술 트렌드

- 해당 도메인에서 주로 사용되는 기술 패턴
- 신기술 적용 사례:
  - AI/ML 활용
  - 음성/자연어 인터페이스
  - AR/VR
  - 실시간 처리
  - 엣지 컴퓨팅
  - 기타 도메인 특화 기술
- 오픈소스/SaaS 생태계 변화

### 3. 적용 판단

각 트렌드에 대해:
- **적용**: 이 프로젝트에 직접 활용 가능 + 사유
- **보류**: 관심은 있으나 MVP 범위 밖 + 사유
- **미적용**: 이 프로젝트와 무관 + 사유

## WebSearch 키워드 패턴

```
"{도메인} 시장 트렌드 {현재연도}"
"{도메인} 기술 트렌드"
"{도메인} AI 활용 사례"
"{도메인} 스타트업 투자"
"{도메인} 시장 규모 성장률"
```

## 출력 형식

```markdown
# Trend Analysis: {도메인명}

> 조사일: {YYYY-MM-DD}

## 시장 트렌드

| # | 트렌드 | 설명 | 출처 | 적용 판단 |
|---|--------|------|------|----------|
| 1 | {트렌드} | {1~2줄} | {URL or [일반 지식 폴백]} | 적용/보류/미적용 |

### 주요 트렌드 상세

#### {트렌드 1}
- 배경: ...
- 현황: ...
- 이 프로젝트에의 시사점: ...

## 기술 트렌드

| # | 기술/패턴 | 도메인 적용 사례 | 성숙도 | 적용 판단 |
|---|----------|----------------|--------|----------|
| 1 | {기술} | {사례} | 초기/성장/성숙 | 적용/보류/미적용 |

### 주목할 기술 상세

#### {기술 1}
- 개요: ...
- 도메인 활용 사례: ...
- 도입 시 고려사항: ...

## 시사점

### 적용 권장 트렌드
- {트렌드/기술}: {이유} → {구체적 적용 방안}

### 향후 관찰 대상
- {트렌드/기술}: {현재는 보류하지만 주시 이유}
```

## 규칙

- 모든 트렌드에 출처 명시
- 적용 판단은 반드시 사유 포함
- 기술 성숙도 표기 (초기/성장/성숙)
- 과도한 기술 낙관 지양 — 실제 도입 사례 기반
