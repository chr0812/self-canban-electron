# 웹사이트 UI/UX 조사 체크리스트

## 필수 조사 항목

### 레이아웃
- [ ] 패턴 선택: 히어로형 / 매거진형 / 포트폴리오형 / 랜딩형 / 커머스형
- [ ] 콘텐츠 최대 너비 (1200px / 1440px / 풀와이드)
- [ ] 그리드 시스템 (12컬럼 등)
- [ ] 위/아래 스크롤 깊이 전략

### 네비게이션
- [ ] 헤더 고정 여부 (sticky/fixed)
- [ ] 메가메뉴 vs 드롭다운 vs 단순 링크
- [ ] 모바일 햄버거 메뉴 패턴
- [ ] 푸터 네비게이션 구조
- [ ] 사이트맵/브레드크럼

### SEO/퍼포먼스
- [ ] 시맨틱 HTML 구조 (h1~h6, article, section)
- [ ] OG 태그 / 메타 설명
- [ ] 이미지 최적화 (WebP, lazy loading)
- [ ] Core Web Vitals (LCP, FID, CLS)
- [ ] SSR/SSG 전략

### 콘텐츠 표현
- [ ] 히어로 섹션 패턴 (영상/이미지/텍스트/슬라이더)
- [ ] CTA 버튼 배치 전략
- [ ] 소셜 프루프 (리뷰, 통계, 로고월)
- [ ] 컨텐츠 섹션 간 전환 (스크롤 기반 애니메이션)
- [ ] 이미지/비디오 갤러리 패턴

### 반응형
- [ ] 모바일 퍼스트 vs 데스크톱 퍼스트
- [ ] 브레이크포인트 (mobile/tablet/desktop/wide)
- [ ] 이미지 아트 디렉션 (뷰포트별 다른 이미지)
- [ ] 타이포그래피 스케일 (뷰포트별 폰트 사이즈)

### 인터랙션
- [ ] 스크롤 애니메이션 (Intersection Observer)
- [ ] 호버 효과 (데스크톱 전용)
- [ ] 페이지 전환 효과
- [ ] 마이크로 인터랙션 (버튼, 입력, 알림)

### 신뢰/전환
- [ ] 위 더 폴드 (스크롤 없이 보이는 영역) 최적화
- [ ] 전환 퍼널 최적화 (CTA → 폼 → 완료)
- [ ] 신뢰 요소 (인증 마크, 리뷰, 보안 배지)
- [ ] A/B 테스트 대응 구조

### 접근성
- [ ] 스크린리더 호환
- [ ] 키보드 네비게이션
- [ ] 색상 대비 (WCAG 2.1 AA)
- [ ] alt 텍스트, aria 레이블

### 커머스 특화 (해당 시)
- [ ] 상품 그리드 (2/3/4열 전환)
- [ ] 상품 카드 패턴 (이미지, 가격, 뱃지)
- [ ] 장바구니 UX (미니카트, 사이드 패널)
- [ ] 결제 플로우 (단계, 게스트 결제)
- [ ] 검색/필터 UX

## 벤치마킹 관점

동종 웹사이트 분석 시 확인할 항목:
| 관점 | 확인 내용 |
|------|----------|
| 첫인상 | 히어로 구성, 위 더 폴드 정보, 로딩 속도 |
| 정보 구조 | 메뉴 뎁스, 콘텐츠 그룹핑, 탐색 용이성 |
| 전환 설계 | CTA 위치, 폼 간결성, 전환 퍼널 |
| 모바일 대응 | 반응형 품질, 터치 UX, 모바일 메뉴 |
| 차별화 | 인터랙션, 브랜딩, 콘텐츠 전략 |
