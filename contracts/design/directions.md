# 디자인 방향 목록

화면 시안(`design-ui-direction`이 만든다)을 **서로 다른 방향**으로 만들기 위한 목록이다. 한 번에 3개(작은 프로젝트는 2개)를 골라 시안으로 그리고, 사용자가 고르거나 조합한다.

방향은 같은 8개 **축**의 값으로 정의한다. 시안끼리 서로 다른 축이 5개 이상이어야 한다(게이트 `DSN-02`). 같은 틀에서 색만 바꾼 시안은 방향이 아니다.

## 축과 쓸 수 있는 값

| 축 | 쓸 수 있는 값 |
|----|--------------|
| 글자 | 세리프 중심 / 산세리프 기하형 / 산세리프 인문형 / 모노스페이스 포인트 / 한글 명조·고딕 조합 |
| 색 논리 | 단색+강조 한 점 / 무채색+원색 한 가지 / 유사색 계조 / 보색 대비 / 자연색 |
| 밀도 | 여백 넓음 / 보통 / 고밀도 |
| 모양 | 직각·선 중심 / 둥근 / 유기적 곡선 / 두꺼운 외곽선 |
| 구성 | 에디토리얼 / 격자 / 단일 열 흐름 / 대시보드 |
| 장식 | 없음 / 일러스트 / 사진 중심 / 패턴·질감 |
| 움직임 | 거의 없음 / 전환 중심 / 피드백 중심 |
| 어조 | 담백 / 친근 / 전문적 / 장난기 |

프로젝트가 이 값 밖의 값을 쓰면(브랜드 지정 등) 시안의 축 비교 표에 그 값을 적고 사유를 한 줄 덧붙인다.

## 방향 설명

각 방향의 **잘 맞는 곳**, **대가**, **함정**(`anti-slop.md`에서 특히 조심할 것)이다. 시안 설명에 대가를 반드시 함께 적는다.

| 방향 | 잘 맞는 곳 | 대가 | 함정 |
|------|-----------|------|------|
| 에디토리얼 | 읽는 것이 중심인 서비스, 큰 숫자·사진을 앞세우는 화면, 한 번에 하나만 보여 주는 흐름 | 한 화면에 담는 정보가 적고, 정보가 많은 목록·표에는 불리하다 | 큰 기울임 세리프 제목으로 편집 느낌을 때우는 것 (Beautifully Crafted) |
| 고밀도 도구 | 자주 쓰는 업무 도구, 기록을 비교하는 사용자, 관리 화면 | 첫 사용자가 압도될 수 있고 작은 글자로 흐르기 쉽다 | 글자가 너무 작아지는 것, 모든 패널이 같은 비중인 것 |
| 부드러운 생활형 | 일상·가족·건강처럼 정서가 중요한 서비스, 비전문가 사용자 | 숫자·데이터가 장식에 묻힐 수 있고 진지한 도구로는 가벼워 보인다 | 모서리를 과하게 둥글게(44px radius), 자리표시 느낌 일러스트 |
| 직각 격자 | 개성이 중요한 서비스, 젊은 층, 구성이 단순한 앱 | 호불호가 갈리고 장시간 쓰기엔 피곤할 수 있다 | 보색 대비가 네온처럼 되는 것, 패턴이 가독성을 해치는 것 |
| 자연·사진형 | 사진·장소·식음료처럼 이미지가 중심인 서비스 | 사진 자원이 필요하고 이미지가 없으면 비어 보인다 | 이미지 위 거의 불투명한 막, 크림·베이지를 고민 없이 쓰는 것 |
| 절제된 전문가형 | 금융·업무·의료처럼 신뢰가 중요한 서비스 | 개성이 약해 다른 서비스와 비슷해 보일 수 있다 | 기본값 글꼴, 모든 카드가 같은 비중인 것 |

## 선택 규칙

1. **도메인과 타겟으로 후보를 좁힌다.** PRD의 타겟 사용자와 서비스 성격이 기준이다. 트렌드 조사만으로 고르지 않는다. 고른 근거를 시안 설명에 적는다.
2. **취향 답변을 반영한다.** 사용자가 좋아한다고 한 서비스·싫어한다고 한 느낌이 있으면 그 방향을 한 시안에 쓰고, 싫어하는 느낌과 겹치는 방향은 뺀다.
3. **서로 다른 방향으로 고른다.** 아래 "가까운 쌍"에 있는 두 방향을 같은 묶음에 넣지 않는다. 고른 묶음의 모든 쌍이 서로 다른 축 5개 이상이어야 한다.
4. **기본값 조합을 시안으로 내지 않는다.** 기본값 글꼴, 보라-파랑 그라데이션, 카드 안의 카드, 아이콘 타일 제목 같은 조합은 어느 방향에서도 쓰지 않는다 (`anti-slop.md`).
5. **사용자가 브랜드·참고 사이트를 제공했으면** 한 시안은 그것을 따른다.
6. **시안을 그릴 때는 명세의 용어와 실제 예시 데이터로 쓴다.** 대표 화면은 핵심 시나리오의 `SCR` 1~2개다.

## 가까운 쌍 (같은 묶음에 넣지 않는다)

서로 다른 축이 5개 미만인 쌍이다. 이 목록은 위 표에서 계산한 것이고, 테스트가 표와의 일치를 확인한다.

| 쌍 | 서로 다른 축 |
|----|--------------|
| 에디토리얼 ~ 절제된 전문가형 | 3 |

경계(정확히 5개)인 쌍: 고밀도 도구 ~ 절제된 전문가형, 부드러운 생활형 ~ 자연·사진형. 같은 묶음에 넣을 수는 있지만, 그때는 나머지 시안과의 차이를 더 크게 잡는다.
