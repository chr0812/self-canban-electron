## Personas

### Persona 1: 사용자 본인 (유일한 Persona)
- 나이/직업: 말하지 않음. 개발 버그와 할 일을 모두 다룬다고 했으므로 개발 업무를 하는 사람일 가능성이 있으나 추론이다 [I]
- 목표: 해야 할 일을 한 화면에 모아 등록부터 해결까지 관리한다
- 맥락: 내 PC 한 대, 인터넷이 없어도 쓴다
- 불편사항: 지금 쓰는 도구가 없다 (인터뷰 R1). 구체적 불편 사례는 듣지 못했다 (Q-001)

> 사용자가 본인 1명이라 Persona를 하나만 둔다. 부 사용자와 엣지 사용자는 없다 (계정·공유 기능 없음).

## 핵심 여정

### Journey 1: 카드 등록부터 해결까지 (사용자 본인)

설명: 개발 버그나 할 일 한 건이 생겨 카드로 만들고, 상태를 바꿔 가며 진행 기록을 남기고, 끝나면 보관한다.

| 단계 | 사용자 행동 | 시스템 응답 | 필요 기능 (FR) | 화면 (SCR) |
|------|-----------|-----------|---------------|----------|
| 1. 진입 | 앱을 연다 | 저장된 카드를 상태별 보드로 보여 준다 | FR-003, FR-006 | SCR-001 |
| 2. 등록 | 카드를 만들고 종류·설명·마감일·우선순위를 적는다 | 할 일 칸에 새 카드가 나타난다 | FR-001, FR-004, FR-007, FR-008 | SCR-002, SCR-001 |
| 3. 진행 | 상태를 진행 중으로 바꾸고 기록을 남긴다 | 카드가 진행 중 칸으로 옮겨지고 기록이 쌓인다 | FR-002, FR-009 | SCR-001, SCR-002 |
| 4. 해결 | 상태를 완료로 바꾼다 | 카드가 완료 칸으로 옮겨진다 | FR-002 | SCR-001 |
| 5. 정리 | 완료 카드를 보관한다 | 카드가 보드에서 사라진다 | FR-010 | SCR-001 |
| 6. 이탈 | 앱을 닫는다 | 변경 내용이 PC에 저장되어 있다 | FR-006 | SCR-001 |

### Journey 2: 날짜 기준으로 일정 확인 (사용자 본인)

설명: 마감일을 기준으로 해야 할 일을 캘린더에서 보고, 마감이 지난 카드를 확인한다.

| 단계 | 사용자 행동 | 시스템 응답 | 필요 기능 (FR) | 화면 (SCR) |
|------|-----------|-----------|---------------|----------|
| 1. 진입 | 캘린더 화면으로 이동한다 | 마감일이 있는 카드를 날짜 칸에 보여 준다 | FR-005, FR-004 | SCR-003 |
| 2. 확인 | 날짜별 카드를 훑어본다 | - | FR-005 | SCR-003 |
| 3. 지난 카드 확인 | 보드로 돌아와 마감이 지난 카드를 본다 | 지난 카드를 구분해 보여 준다 | FR-012 | SCR-001 |
| 4. 이탈 | 앱을 닫는다 | - | FR-006 | SCR-001 |

### Journey 3: 쌓인 카드에서 찾기 (사용자 본인)

설명: 카드가 쌓인 뒤 검색·필터로 찾고, 보관한 카드를 확인하며, 필요하면 카드를 고치거나 지운다.

| 단계 | 사용자 행동 | 시스템 응답 | 필요 기능 (FR) | 화면 (SCR) |
|------|-----------|-----------|---------------|----------|
| 1. 진입 | 보드에서 검색어를 입력하거나 조건을 고른다 | 조건에 맞는 카드만 보여 준다 | FR-013 | SCR-001 |
| 2. 보관 카드 | 보관함에서 지난 카드를 찾는다 | 보관한 카드 목록을 보여 준다 | FR-010, FR-013 | SCR-004 |
| 3. 수정·삭제 | 카드를 열어 고치거나 지운다 | 변경이 보드와 캘린더에 반영된다 | FR-011 | SCR-002 |
| 4. 이탈 | 앱을 닫는다 | - | FR-006 | SCR-001 |

## Edge Cases

### Edge 1: 처음 실행 (빈 상태)
- 상황: 카드가 하나도 없는 첫 실행
- 사용자 경험: 빈 세 칸이 오류 없이 보인다
- 시스템 대응: 빈 보드를 보여 주고 카드를 만들 수 있게 한다
- 관련 FR: FR-003 (AC-006), FR-006

### Edge 2: 카드 삭제 (오류·되돌릴 수 없는 동작)
- 상황: 사용자가 잘못 눌러 카드를 삭제한다
- 사용자 경험: 카드가 사라진다. 백업이 없어 복구할 수 없다 (D-009)
- 시스템 대응: 삭제 확인과 되돌리기 여부는 사용자가 말하지 않았다
- 관련 FR: FR-011 → CAND-004

### Edge 3: 카드가 수백~수천 건 (대량 데이터)
- 상황: 1년 쓰면 카드가 수백~수천 건 쌓일 수 있다 (ASM-010)
- 사용자 경험: 보드와 검색이 느려지지 않아야 한다. 기준 수치는 말하지 않았다
- 시스템 대응: 완료 카드 보관(FR-010)과 검색·필터(FR-013)가 이를 다룬다
- 관련 FR: FR-010, FR-013 → CAND-002

### Edge 4: 인터넷 없음 (오류 상황)
- 상황: PC가 네트워크에 연결되어 있지 않다
- 사용자 경험: 모든 기능이 평소처럼 동작한다
- 시스템 대응: 외부 요청 없이 동작한다 (NFR-001)
- 관련 FR: FR-006

## 발견된 잠재 요구사항

### 핵심 여정 누락 → Candidate 후보 (사용자 확인 후 FR로 승격)
- 보관한 카드를 보드로 되돌리는 보관 해제 (J3 단계 2) → CAND-003

### 엣지/편의 → Candidate Requirements 후보
- 카드 삭제 확인·되돌리기, 삭제 시 진행 기록 처리 (Edge 2) → CAND-004
- 카드가 많을 때 응답 시간 기준 (Edge 3) → CAND-002
